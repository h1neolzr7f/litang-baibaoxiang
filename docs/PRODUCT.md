# 产品说明

理塘百宝箱只做本地后处理：**超分、打码、清元数据**。不管生图、不管上传。

## 给谁用

把 NovelAI / 本地绘好的图批量收拾成能外发的成品。Windows 适合十几 GB 文件夹；手机适合出门改几张。

## Windows 默认

- 超分开，Real-CUGAN 专业版，2 倍，偏保守细节
- 打码开，像素，强度 36，外扩 28，识别灵敏度 8
- 四部位全开（欧西利无独立类别）
- 清元数据开
- 成品放你选的文件夹，已有同等效果的跳过

## 不会做的事

- 不改原图
- 不把图片传到我们的服务器
- 不保证每一处敏感部位都检得出来
- 一键包依赖本机显卡驱动；没有独立显卡也能跑，只是更慢
