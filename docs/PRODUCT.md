# 产品说明

理塘百宝箱只做本地后处理：**超分、打码、清元数据**。不管生图、不管上传。

## 给谁用

把 NovelAI / 本地绘好的图批量收拾成能外发的成品。Windows 适合十几 GB 文件夹；手机适合出门改几张。

## 当前 Windows 版本

**2.4.4**。「开始处理」在绿色拖放区和窗口底栏各有一颗，确认框的「确认开始」钉在底部。矮屏幕或 125% 缩放也不会把主按钮裁掉。处理完成后会留下成功/失败摘要，不会被「没有待处理图片」盖住；处理中会锁住加图和选项；清空队列要确认；关掉全部打码部位会拦住而不是悄悄全开。

## Windows 默认

- 超分开，默认自动选 Real-CUGAN 专业版；也可改标准版、干净版，或本机 Lanczos / 柔和 / 清晰锐化
- 超分风格：偏保守细节（Real-CUGAN 还可改强降噪或无降噪）
- 打码开，像素，强度 36，外扩 28，识别灵敏度 8
- 四部位全开（欧西利无独立类别）
- 清元数据开
- 成品放你选的文件夹，已有同等效果的跳过

## 不会做的事

- 不改原图
- 不把图片传到我们的服务器
- 不保证每一处敏感部位都检得出来
- 一键包依赖本机显卡驱动；没有独立显卡也能跑，只是更慢
